# 🥬 Nature's Platter

A modern and responsive grocery shopping landing page built with **HTML** and **Tailwind CSS**.
The project focuses on a clean UI, responsive layouts, product cards, promotional offers, subscription section, and mobile-friendly navigation.

## 💻 How to Run

No installation or build process is required.

### 1. Clone the repository

```bash
git clone https://github.com/your-username/natures-platter.git
```

### 2. Open the project

```bash
cd natures-platter
```

### 3. Run the website

Simply open `index.html` in your browser.

You can also use **Live Server** in VS Code for a better development experience.

## 📱 Responsive Design

The website is designed to work across different screen sizes:

* 📱 Mobile
* 📲 Tablet
* 💻 Laptop
* 🖥️ Desktop

Tailwind CSS responsive utilities such as `md:` and `xl:` are used throughout the project to adjust layouts for different screen sizes.

## 🎨 Main Sections

### Hero Section

Introduces the grocery store with a headline, description, and promotional hero image.

### Services

Highlights:

* 24/7 Services
* Fast Delivery
* Healthy Products

### Popular Products

Displays grocery products such as:

* Onion
* Tomato
* Potato

along with ratings and prices.

### Arrival & Offers

Contains promotional offers from featured brands with discount information.

### Grocery News

A newsletter subscription section where users can enter their email to receive grocery news and deals.

### Footer

Includes navigation links, brand information, and social media links.

## 📦 Dependencies

This project uses CDN-based dependencies, so no package installation is required.

### Tailwind CSS

```html
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

### Font Awesome

```html
<link
  rel="stylesheet"
  href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.3.1/css/all.min.css"
/>
```
